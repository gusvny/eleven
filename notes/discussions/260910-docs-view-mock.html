工单工作流台设计

Statusfinal ✓ Verified 09-10 Categorydesign Updated2026-09-04 Pathdocs/design/工单工作流台设计.md

工单台把「一张工单的一生」搬进可读视图：工单列表给全局，详情抽屉给纵深，人门给审批。本文是这套 UI 的设计准则与不变式。

1. 工单列表

列表平铺不分组，状态靠配色区分：等你=黄调、受阻=红调、活跃=常规。每行右侧的派生动作位只做导航，零写操作。

2. 详情抽屉

2.1 操作条

操作条钉在头部下方，主操作平铺、低频收「更多」。任何页签都能看到状态、直接操作。

2.2 快照要点

快照要点 = 阶段时间线 + 最近交接 + 门与签字记录 + 工作流快照，全部 ticket show 直读。

3. 人门与签字

到终态前若出口=human，stage_state=awaiting-human，UI 标「等你签字」。

stage_state含义UI 表现
awaiting-human等人签字「等你签字」徽标
blocked机械校验受阻红调 + 原因横幅
running进行中常规色
