## 1 五族与它们的病

### 族 A · 等**真实墙钟上界**（最贵、最不稳）
- **代表**：`t260912-03-authz-overlimit-accept` 603 s —— 它的断言是"**等 600 s** 看有没有到 blocked"；`t260905-02`（sleep ×6，600 常量）、`t260905-10`（poll ×13，300/600 常量）同型。
- **不合理在哪**：①**它测的不是产品行为，而是"我们愿意等多久"**——把生产上界当测试步长，等于让测试替产品耐心；②**负载越重它越慢**（本就在负载窗口里跑），②③ 同一件事（超限被拒、下轮可见）**本来可以注入**（本仓已有 `wait_bound_ms` 这类参数形状）；④阻塞时间吃掉并发额度，是"一条慢 = 全轮慢"的根源。
- **应该怎么测**：**上界可注入**（设 1–2 s），断言"**上界触发** + 拒绝**具名点名**"；时间语义优先走 **Temporal 进程内测试环境**（虚拟时钟，真实耗时 ≈0）；不再有 `sleep(300)`。

### 族 B · 真 docker 台跑链路（慢有理由，但**用错了场景**）
- **代表**：`t260915-12-gate-real-chain` 258 s、`t260913-01` 92.7 s、`t260912-03-authz-cli-queryable` 92.4 s、`t260916-28` 50.2 s、`t260924-04` 113 s（真 docker 台＋真 worker＋真 workflow＋真 CLI）。
- **不合理在哪**：①"真 worker/真 workflow/真 CLI 的**时序与信号语义**"**不需要容器**——Temporal Python SDK 自带**进程内测试服务器**（真 Temporal、无 docker、可时间跳过）；②只有**容器边界本身**（网段/限额/进程组回收/ENV 透传）才真的必须 docker；③把"必须真台"和"只是想要真"混在一起，让整轮替少数条买单。
- **应该怎么测**：**分流**——(i) 信号/时序/落账面改走**进程内服务器 + 桩 + 真 CLI**；(ii) 真容器面（`t260912-02` 32 台并发网段、进程组回收）**保留**，但标 `cost: minutes` 且**按票/夜间触发**，不进每轮。

### 族 C · 自己 spawn 整套东西（**机制测试跑了全域**）
- **代表**：`t261004-20-test-anchor-brakes` 180 s（两次**整副 lint**）、`t261009-12-lint-verdict-stable-or-named` 92.8 s（多次 lint）、`t261004-25-anchor-presence-lint` 67.5 s（两次 lint）、`t261004-26-hostile-identity-fixture-chain` 97.8 s（嵌套套件 ×3）。
- **不合理在哪**：**测的是机制（"种病灶→红→点名"或"同样输入两次判定一致"），却把全域（整副 lint／整套件）当输入**。宿主一句话点破：「你这是测 lint 的机制，又不是测具体 lint 什么」。
- **应该怎么测**：①给 `lint_tests.py` **子集选择器**（`--rules`/`--only`）；②刹车只跑**它种的那条/那几条规则**；③"判定一致性"用**最小子集两次**即可；④嵌套跑套件的：改成**直接调那条链**或**按需**。

### 族 D · **轮询等文件/状态出现**（该改握手）
- **代表**：`t261009-52-fixture-leak-brakes` 213 s（轮询等夹具文件出现才发信号）。
- **不合理在哪**：**用固定间隔轮询代替事件**——测试等待的是"另一个人做了某事"，那件事发生时**子进程自己知道**，写一行给父进程即可；轮询窗越稳越长，越慢。
- **应该怎么测**：**握手**（子进程建好文件即写一行 stdout，父进程据此动手）；`plant` 种到**临时副本**（顺带脱掉 exclusive 约束、可并行）。

### 族 E · 真机/真会话面（**慢有正当理由，但进错了轮次**）
- **代表**：`auto-rework-trace` 90.3 s（真 console ＋ 五个自动打回场景）、`t260912-02-burst-managed-subnets` 87.8 s（32 台真台同瞬爆发，证网段/保险丝）、`t260929-04-wake-real-session-bench` 73.8 s（真宿主真会话）、`t261002-13-tmp-backlog-sweep-safety` 58 s（真子进程 × 真沙盒）。
- **不合理在哪**：**不是测法错，而是把"证一次性事实的真机面"放进**每一轮**。这类面证的是"在真机/真台上确实如此"，本来就该**按票/夜间/发版前**跑。
- **应该怎么测**：保留，但声明 `cost: minutes` 与触发条件（例如"只在涉及该面的票 + 每晚一次"），**不进每轮**。

## 2 七条通用原则（建议写进用例设计纪律）

1. **测机制 ≠ 测全域**：机制类证明只需要"能触发该机制的最小面"。
2. **上界必须可注入**：任何"等到 X 发生/等到超时"的断言，上界是参数，测试设**秒级**；睡生产上界＝缺陷。
3. **时间语义用虚拟时钟**（Temporal 进程内测试环境 time-skipping）。
4. **用夹具替换真系统**：真容器 ↔ 进程内服务器/桩/临时副本；**只有"容器边界本身"才配 docker**。
5. **握手代替轮询**：事件的产生者写一行，消费者据此动手。
6. **per-diff 代替全树**：lint/扫描类只跑被改文件（`lint_tests.py --base` 已支持）。
7. **每条声明 `cost:` ＋ 硬上界**，超预算＝**具名失败**；且**轮次范围要与 cost 匹配**（`seconds` 进每轮，`minutes` 按需）。
