注册到 ~/.sandbar/projects/<key>/ · 单根模型：多 repo 项目填父目录（票的空间=根下 .lane/）

  • key 形状合法 / 未注册 / 根目录存在 / 不与既有项目交叉或互为父子
  • verify.yaml 缺失——首张 dev-lane 票会在 integration 道红（项目自备，不代写）
  • per-key 凭据不存在——回落平台 global（弃用窗口）；隔离需求：install -m 0600 …
  • paths 未声明——roles/模型路由回落现行约定
黄牌不阻塞（契约三态：缺失=关闭/回落）。确认后左栏即时出现新项目组（含 ⚙）。
