## 1. 为什么单开一面，以及今天它是什么状态（实测）

文档在这个仓里是有权威的产物：`docs/` 是归档柜（设计准则、接口契约、操作事实），
`notes/` 是草稿纸（讨论稿、立项单、KI 册、epic 记录）。它们出错的方式和代码不一样，
所以需要自己的判据。

实测现状（261004）：

- **这一面从没真正跑起来**：`sandbar-inspection-docs-sync` 排程 `num_actions=0`（从未触发）；
  台账只有一期 `20260915`，而且是**手动**跑的，产出 **140 条 med 全属假报**
  （相对路径按仓根解析错 + 参数是 260928 英文化之前的旧中文文件名），该期在**人门被 reject**
  （`who=op-121fow`，timeline 可查）。
- **判据只有三条粗线**：文档与代码脱节 / 索引漂移 / 断链；且**只盯 `docs/`**，不碰 `notes/`。
- **体量允许全量**：`docs/` 25 篇 12.4 万 token + `notes/` 60 篇 27.6 万 token
  ≈ **40 万 token**——代码面是 700 万，只能切片轮读；文档面每期能覆盖全部。
- **节奏（261004 宿主令）**：**每天 10:00**（原每周一）。
  空转开关 `skip_when_unchanged` **未给本实例**：生产声明里有一条既有契约
  「只有 simplify-face 开空转，别的实例必须真跑」（`test_260929_inspection_no_change_skip.py`），
  破例是另一个决定 → 见 §8 未决。不破例的代价是：整仓一点没动的那天也会**全量重读**
  内容完全相同的 40 万 token 文档。

## 2. 判据三分法（这一刀是所有设计的前提）

| 类 | 范围 | 判什么 | **不**判什么 |
|---|---|---|---|
| **规范面** | `docs/reference/*`、`testing-guide.md`、`terminology.md`、`docs/README.md`（索引）、`docs/ops/*runbook`、`inspection-sample.yaml`、被别处当「现行真源」引用的页 | **它说的话必须与现状一致**：路径/命令/入口真的存在；结论与代码、票账对得上；页面之间不互相打脸；被取代的必须写明被谁取代 | 文风偏好、篇幅 |
| **历史面** | `docs/design/*`（定稿记录＝某时点的事实） | 仅两件：①是否仍被别处当「现行真源」引用（是 → 要么加 supersede 指针、要么降级）；②它宣称的后续动作是否真的发生过 / 已被谁取代 | **路径漂移**（历史引用失效是历史事实，不是缺陷） |
| **草稿面** | `notes/`（讨论稿、立项单、KI 册、epic） | **决策有没有毕业**（定过的事进没进 `docs/` 或代码）；立项单票序与实际票对得上；KI 条目状态与现实一致；epic 已完结的死稿 | 草稿的语言风格、未定稿的措辞 |

## 3. 机械层（宿主 261004 批准复活）

**定位**：能写出确定判据、答案非黑即白、跑全量也不贵、同一输入永远同一结论的那一半。
它跑**全库**，每期都跑。

| # | 检查 | 抓什么 | 今天实测 |
|---|---|---|---|
| M1 | 索引三口径一致（`index.json` ↔ `docs/README.md` ↔ 实际文件） | 页在但没登记 / 登记了但文件没了 / frontmatter 五字段缺 | **1 条真缺陷**（`reference/panel-list-conventions.md` 未登记） |
| M2 | 引用路径可达（**只判规范面**） | 文档指向不存在的文件/脚本/命令入口 | **2 条真缺陷**（`testing-guide.md` → `notes/epics/epic-linkage.md`） |
| M3 | 术语表（L7）+ 语言纪律 | 按 diff 只查**新增行**：`docs/` 走英文 STE、`notes/` 走受控中文（261004 口径，存量不动） | — |
| M4 | 「进度/待办/工单清单」写进文档 | 纪律违反（登记表必变死表） | — |
| M5 | 文档点名的票号 / commit / 文件引用存在性 | 引用空气 | — |
| M6 | `docs/design` 的 supersede 指针齐 | 被取代的稿子没写明被谁取代 | — |
| M7 | **代码变化面 → 提到这些面的文档**（新补） | 「代码改了文档没跟」；反向也查：文档改了但代码现状不符 | **今天完全没有这一环** |

**复用与不照抄**：M1/M2 与「frontmatter 合法性」三条规则**已有一版实现**——
`server/engine/inspection_scan_doc.py` 的 S8/S9/S10（t260916-22 退役留档）。
但那份模块**不许原样接线复活**（它自己头注写着「新代码禁接线本模块」）：
把三条规则**按类收窄**后重写进新的机械路径，退役注释由落地票一并更新。照搬时必须
逐项声明带过来/不带+理由——S10 的相对路径解析当年就是 140 条假报的病根，
带过来必须带**修好的解析**（按文档所在目录解析，且不把 `*.d.ts` 这类通配当路径）。

**假报治理（三条，缺一不可）**：

1. **按类收窄**：历史面豁免路径漂移（否则今天 64 条里 28 条来自一个归档页）；
2. **规则写窄**：只认显式形态（markdown 链接、反引号路径 + 已知后缀），不全文猜路径；
3. **显式豁免**：命中但确属合法固定面的，用注释声明豁免（`<!-- doc-exempt: <规则id> -->`），
   豁免本身可审——不靠沉默。

**产出形态**：机械发现与 agent 发现**同形状**（同一严重度词表、同一 `evidence{path,line,quote}`
格式、`scan` 字段标规则 id 便于溯源、id 由内容哈希铸造跨期稳定），所以面板、报告、裁定、
去重四条管道只走一套。

## 4. agent 层（判断）

- **全量读**：每期覆盖全部文档（分片执行——分片是执行细节，不是覆盖打折；分片数按巡检
  agent 的窗口与超时定，**窗口按路由实测，不写死**）。
- **两向核对 + 一个缺口方向**：
  - **代码 → 文档**：本期变化面为驱动，M7 算出的「必校清单」逐条核；
  - **文档 → 代码**：全量文档的每条事实性断言回到代码/票账/文件系统核对；
  - **缺口**：本期变了的关键面（授权面、面板 API、引擎入口、巡检声明、判据文档）
    **没有任何文档提到** → 该不该补页。
- **判断类型**：该毕业的决策毕业了吗（只在 note 里定过、没进 `docs` 或代码）；
  同一条规则是不是抄了两份（真源唯一）；结论是否已被现实推翻。
- **报告做差分**：每期只出**新增 / 仍存在 / 已消解**三类（跨期稳定 id + 假报压制已在）。

## 5. 范围与预算

- **范围＝全库文档清单**（不是「本期变过的文件」清单）。本期变化面只用来**排序与点名必校项**。
- **范围规则为这一面开例外**：允许读**仓内任意文件**来核对文档所述（只读；仍禁子代理）。
  现有 prompt 里「审查范围=本清单，清单之外的文件一律不看」是给代码面定的，套在文档面上
  等于让它无法核对——这是本面必须改掉的一条。
- 预算：发现上限、inspect 超时沿用引擎缺省（`inspect_max_findings=40`、
  `inspect_timeout_min=60`），需要时在实例声明里覆盖。

## 6. 产出与处置

- 发现**只报告不改**（红线不变）；处置：小修（错链、未登记、术语）**攒批**走一张小修票；
  结论级错位单独一票；`docs/design` 是受保护路径，改动必须人审。
- 每期落期台账 `out/inspection/inspection-docs-sync-<期号>.json`；
  「被审过的文件」落项目台账（一行一文件 + 期号/时间），供给滚动覆盖度查询。

## 7. 面板

- Inspection tab 里 Documents 是一张**面卡**（与 Integration tests / Simplify 并列），
  字段：强度计数、`documents read`（全量）、`must-check list`（M7 命中数）、`gaps`、
  三类篇数分述、分片数，以及**本面本期的报告入口**；本期没跑就如实写「本实例本期无报告 + 上次/下次」。
- **覆盖度按滚动窗口看**（`this period / 7 days / 30 days / all`，默认 7 天），
  三行分写：代码（切片口径）、文档（全量口径）、队列（当前状态）。
