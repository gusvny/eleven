# 261004 顶栏横幅：换成 sandbar（宿主 261004）

> 状态：**草稿＋mock**（宿主令「先 mock，不要急着开票」）。视觉基准＝
> `notes/discussions/261004-concurrency-limit-mock.html`（顶栏 26px 那条）。

## 1. 现状（读 dsh 安装树，非推测）

- **产品名是硬编码的**：`@deepseek-ai/dsh-client-ui-layout/lib/client.js` 里
  `const productTitle = "DeepSeek Harness";`——用于 `document.title`，并传进 App 壳；
  **没有任何配置面**可改（找过 `productTitle / productName / appTitle / brandName`，只有这一处与设置页文案）。
- **壳暴露的插槽**：`renderSlot("sidebar" | "main" | "rightbar" | "shell.overlay")`——**没有 titlebar 插槽**。
- **壳的自声明属性**（可作锚）：`data-sidebar-collapsed` / `data-rightbar-collapsed` /
  `data-rightbar-fullscreen` / `data-rightbar-instant` / `data-dragging`；布局 API 有
  `toggleSidebar()`（收起左栏），以及 `onSidebarDrag` 拖拽改宽（`clampWidth(px, 264, 420)`）。
- **本仓纪律**：不改 dsh 本体（安装树只读）。⇒ 换横幅只能在**我们的客户端插件**里做。

## 2. 可行的做法（两条路，都能不改 dsh）

| 路线 | 做法 | 代价 |
| --- | --- | --- |
| **A. `shell.overlay` 插槽**（推荐） | 用官方插槽渲染一条 26px 全宽横幅；再把平台壳整体下移 26px（改壳的 padding/margin——**有先例**：本仓 `sidebar.tsx` 已经在改壳的 `grid-template-columns`） | 依赖壳的 DOM 结构（改壳样式），需要不变量断言 + 失败时不静默 |
| **B. `sidebar` 插槽内侧** | 横幅只画在左栏顶部（我们自己的槽位，零 DOM 手术） | 不是全宽；中/右栏上方仍留给平台 |

**藏掉平台那条**（DeepSeek Harness + fold 按钮）：只能靠注入 CSS 锚定平台元素。
锚优先用**自声明属性**（若有），否则只能靠结构/类名 ⇒ **脆弱**。纪律：
①把锚写成具名常量并注明出处；②加守卫场景——锚不在时**什么都不藏**并显式记一行（绝不半藏半留）；
③平台的 banner 元素若正好是我们海报覆盖的那一层，可以先只做"覆盖"不做"隐藏"，最坏情形退化为视觉重影而不是空白。

**窗口标题**（`document.title`）是平台写的，我们顶多在我们这层再改写它——**不建议**（会和平台抢同一个字段）。

## 3. 设计（mock 已画）

一条 **26px** 的横幅，横贯三栏之上：

```
[标记] Sandbar                                                        ◐   «
```

- **命名（宿主 261004）**：`Sandbar`（大写 S）；**不要副标**（原来的 `ticket engine` 已删）；
- **标记**：14px，两个候选形态之外**共三个候选**，mock 里点标记循环切换，宿主挑一个：
  - **A 沙脊拱 + 水线**：实心拱坐在一条水线上（"露出水面的沙洲"）；
  - **B 双波**：上细下粗两道波（水与沙）；
  - **C 斜沙洲**：两枚错开的圆角斜条（俯视的沙洲）。
  三者都避开常见 UI 形状（圆点/方块/三角/齿轮），14px 下可辨识；
- **右**：两个**图标钮**——主题切换（`◐`，从面板头挪上来：主题是**全局**的，不该挂在某个面板里）与折叠（`«`）；
- **高度 26px**（宿主：别占空间）；颜色只吃主题 token，深浅色都验过。

**关于那个 fold 按钮**：它本来折左栏（平台 `toggleSidebar`），而**拖分隔条**已经能改宽度
（`clampWidth 264–420`）。所以两个选项：①横幅里保留**一个**图标钮（mock 现状）；②整条去掉折叠，
只靠拖拽。**我倾向 ①**（26px 的带子里一个图标几乎不占地方，折叠仍是常用的"给 chat 让位"动作）。

## 3.1 底部入口（宿主 261004：「底部还有 deepseek harness 的 settings 按钮，以及我们的 metrics 入口」）

| 入口 | 归属 | 处置 |
| --- | --- | --- |
| 平台 **Settings** 按钮 | **全局**（模型、外观等，平台自己的） | **保留**（宿主令） |
| 我们的 **Metrics** 入口（原侧栏 footer） | **项目级观测**（按项目看工单/泳道/闸） | **撤出侧栏底部，改成执行器面板的一个 tab**（宿主提议，采纳） |

**层级一句话**：**底部条 = 全局（平台）；执行器面板的 tab = 本项目**。这样侧栏底部只剩一个入口，
不再把"全局设置"和"项目观测"混在一处。

**面板 tab 顺序**：`Overview · Epics · Grants · Alerts · Ledger · Inspection · Metrics · Docs · Settings`（9 个）。
若嫌长，可把 `Docs` + `Settings` 收进一个 `More`（等你一句话）。
