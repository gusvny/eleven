## 2. 目标与非目标

目标：
1. 发现**语义正确**：不再出现「退役清单被当断言失效」「夹具路径被当仓内资产」类假报；
2. 每条发现**可核验**：必须带 file:line 证据引用，且证据可被机械复核（引用的文件/行真的存在且确实包含所述内容）；
3. 红线不变：巡检只出报告与开票建议，**绝不改码**（agent 只读仓）；
4. 人门不变：approve/reject 收口语义维持现状；
5. 建议修复票只从「agent 判真」的发现出，杜绝噪声洪泛。

非目标：
- 不改 dev-lane 工单引擎与闸语义；
- 不追求扫描级确定性（接受 LLM 输出波动，用证据复核与去重兜底）。

## 4. 关键设计点

### 4.1 role 与模型
- 新增巡检专用 role（建议名 `inspection`，避免与五开发角色混用）：persona=「只读审查员，产出可证伪的发现，宁可少报不可虚报」；
- **【宿主 260916 定】model-routes 为该 role 配 `kimi-coding/k3`**（与 developer 的 zai 系错开账号分摊配额）；
- 用途是**语义审查**（读上下文判「真漂移还是设计如此」），不是替代表达力不足的规则。

### 4.2 输出契约（强 schema）
每条发现：
```json
{
  "id": "内容哈希前 8 位（同内容跨期稳定，供去重）",
  "scan": "agent",
  "severity": "high|med|low",
  "subject": "一句话（含对象 file:line）",
  "evidence": [{"path": "...", "line": 123, "quote": "原文 ≤200 字"}],
  "why": "为什么这是问题（语义判断）",
  "suggestion": "建议（或『无需修，仅记录』）",
  "confidence": 0.0-1.0
}
```
- `evidence` 为**必填且非空**；report 段机械复核：文件存在、行号在范围内、引文与文件内容匹配（容许空白差异）。复核失败 → 该条降级 `unverified` 并在票面点名（不静默丢弃）；
- `suggested_fix_tickets` 只从 `verified && confidence ≥ 阈值 && severity ≥ med` 生成。

### 4.3 防幻觉与成本
- agent 只读（工具面=读文件/grep/读 suite 回执；无写工具）；
- 每期发现条数上限（建议 40，超出按 severity 截断并注明）；
- 泳道内运行（现成隔离面），超时熔断（建议 30 分钟，超时=本期 heartbeat 报「agent 未完成」而非空报告假绿）；
- 跨期去重：`id`（内容哈希）+ (instance) 维度对照上期清单，重复项标记 `recurring` 不再累计计数。

### 4.4 与 deadman/suite 的分工
- deadman（漏跑核查）与 suite（真跑）**保留机械**——它们判「有没有跑/跑没跑过」，是事实面，无需语义；
- agent 只负责「质量面」的语义审查（守卫是否还有效、场景是否冗余、文档是否漂移等，具体审查面按实例 face 配 prompt）。

## 6. 开放问题的裁定（宿主 260916）

1. **模型选型** → ✅ **`kimi-coding/k3`**（宿主定）。
2. **审查面范围** → ✅ **一套通用骨架 + 每 face 一段附加清单**（integration 推荐采纳）：骨架=只读审查员 persona + 证据契约（file:line 必填、引文可机械复核）；分面清单=test 查守卫语义、doc 查文档漂移、stage 查台面容量、mechanism/simplify 按各自关注面。
3. **预算上限** → ✅ **机制做成可配置**；起步值按推荐：发现条数上限 40（超出按 severity 截断并注明）+ 超时 30 分钟（超时=heartbeat 报「agent 未完成」不假绿）。跑两期后按实际用量调。
4. **274 条旧发现** → ✅ **整体作废，不复查**（integration 推荐采纳）：静态扫描假报是机制性的，逐条复核≈白做；期间引擎持续修复会自然消化部分真问题。deadman/suite 两类机械发现（真信号）不随扫描退役、留档跟踪。下期 agent 巡检从干净基线开始。
5. **发现级裁定** → ✅ **要**（宿主 260916 定）：票面 findings 每条可标 `假报/待修/存疑`（人门签字时或签后 CLI 逐条标，纯记账不拦闸）；标签落台账，供跨期去重（`假报` 不再重复计数）与查准率统计。
