3 · 三种"没有东西可看"的状态（今天全是这一栏）

No round recorded yet — the delivery ledger has a landing but no certification and no round ledger row. (Today's reality before t261011-26.)
Round running, no records yet — the runner is up but the suite has not written its header; the tab shows the live progress face only (never an invented count).
Round ended, nothing provable — could not run with the named reason (runner_timeout:3600s / suite_rc_1:run_id_missing_from_summary), so the round is not "red" and not "green": it is no proof.

第三种最要紧：**"没跑成"不能长得像"红"**（红是产品有毛病，没跑成是环境/预算），也不能长得像"绿"。

4 · 口径（写进票面）

① 页面上的每个数都能指到一条记录（轮次台账 / 落地账本 / 进度面），**前端不推导、不兜底成 0**；② run id 是唯一入口锚点（run-<yyyymmdd>-<hhmm>），详情页只认它；③ 计数三态沿用引擎词：pass / fail / env_fail（外加 not yet judged 只作显示，不落账）；④ 冻结/边界/晋级沿用 certification tab 既有面，本页只做"这一轮"的展开；⑤ 保留日志链接指向**稳定路径**（t261011-26 的留存面），不再指向系统 temp。
