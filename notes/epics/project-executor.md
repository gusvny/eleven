## ⓪ 说人话版（一分钟）

**每个项目常驻一个「执行器会话」**：它替你看住本项目的工单——自己代签、自己修卡住的票、
把长活外包给修复票——**只在真不行了才叫你**。

支撑它的是三件东西：

1. **一份项目事件流水**：工单每次状态变化落一条账（跨票、跨工作流、持久、可重建）；
2. **一个独立守望者**：读账、判活、对账、判自锁，在该唤醒它时唤醒、在不行时叫你；
3. **一块面板**：五个 tab——看状态（Overview）、答它的问题（Requests）、看你该知道的事（Alerts）、
   查流水（Ledger）、配权限（Settings）。

## 一、目标（epic 级验收口径）

1. **链路端到端**：一张卡住的票，从被发现到被推起来，**全程在面板可见、在账里可查**
   （谁在什么时候做了什么、凭什么依据、验证结果是什么）。
2. **你不在场时**：需要你的事以**请求**排进面板（带默认动作与期限、不阻塞它继续干活）；
   真卡住（含"它在等自己"）会**叫你**；叫不叫、怎么叫都可配置。
3. **无静默**：账读不到、账与票对不上、守望者自己停跳，都必须**显式可见**（"没数据 ≠ 一切正常"）。
4. **重启不改变事实**：重启后不缺事件（复对账补齐并留痕）、不重播旧提醒、孤儿手被点名、
   半截动作能从 commit 停点续上。
5. **通用**：机制在引擎、面在项目声明；**未声明 = 零行为变化**；默认**最小权限**。

## 二、票序（依赖顺序，逐张验收）

| 票 | 内容 | 依赖 |
| --- | --- | --- |
| **①** | **事件账**（引擎侧）：事件混入 + dev-lane 接线 + 幂等键 + 账格式 + 启动即对账 + 可重建 | — |
| ② | **巡检族接线**：同机制覆盖第二个族（巡检期票/产出发），含 `scope: engine` 的引擎级活动 | ① |
| ③ | **守望者**（宿主插件）：读账、判活、对账、判自锁、按授权唤醒会话、提醒（可配置） | ① |
| ④ | **面板与配置**：五 tab、请求主从视图、授权"轻量过滤式派生"、窗口与保留配置 | ①③ |
| ⑤ | **执行器身份**（每项目预设 + 人设 + charter 段）——可与 ③④ 并行 | — |
| ⑥ | **真唤醒投递**（③ 的最后一跳）：接宿主 Session API 的排队投递 + 队列镜像判「已消化」+ 自醒回环排除 + 真会话「不丢消息」证明 | ③⑤ |

> 票⑥的来历：③ 交付时把「唤醒」按**显式不可用**（探针缝）交付并如实写进交接，而 epic 验收①「被发现→被推起来」的链正缺这一跳，故由宿主 260928 授权补开。epic 已合并票的落地详情查 Temporal / 立项单快照，本文只记票序与依赖。
