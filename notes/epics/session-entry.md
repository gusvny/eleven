## 目标（现行）

让右栏 chat 的项目会话「回得去、建得快、切得动」，会话入口**长在项目上**：
左栏每个项目组内自带会话区（新建 + 切换 + 关闭），右栏 chat 以项目色区分
归属；顶部全局会话入口行在该面验收后退役。

## 第 3 面需求（2026-09-04，原文）

> 我想在每个左栏的项目里增加一个会话区。放在项目分割的下面，工单列表的
> 上面。一横排，包括一个新建会话按钮，和已有会话的tab列表。按钮和tab都是
> 正方形，按钮是一个+号，tab是数字1，2，3，4，代表第几个会话。都是项目
> 级别的。点+号创建一个这个项目的会话。点tab在这个项目已有的会话之间切换。
> 每个tab有关闭按钮，点击后需要弹出确认框，确认了才可以关闭。会话都显示在
> 右栏。当前在右栏的会话，左栏对应的tab高亮。最后，左栏每个项目分配一个
> 颜色，右栏显示chat的时候，要通过这个颜色来区分是哪个project的chat。
> 这个完成测试没有问题交付以后，左栏顶部现在的会话区就可以不要了。

### 需求规格（R1–R8）

- **R1 位置与形态**：左栏每个项目组内、组头（项目分割行）之下、工单列表
  之上，一横排会话区；随项目组折叠态整体隐藏（折叠=整组收起，会话区同隐）。
- **R2 方块元素**：新建按钮 = 正方形「+」；会话 tab = 正方形，显示数字
  1/2/3/4…（该项目内第几个会话）。项目级别，互不混排。tab 数量**不限制**，
  超宽**换行**（不横滚，260904 拍板）。
- **R3 新建**：点「+」在该项目新建会话——落点=该项目主目录（绑工作区、
  复用 blank、工厂同款链，沿用现 handleNew 语义，落点项目=本组项目）。
- **R4 切换**：点 tab 切到该项目已登记会话（右栏显示；平台单 current 语义，
  切换=改 current，全控制台唯一活跃）。
- **R5 关闭**：tab 带关闭钮，点击弹**确认框**，确认后才关（沿用既有关闭
  语义：剔入口 + 入「最近关闭」，不删会话数据）；取消则不动。
- **R6 高亮**：右栏当前会话（current）→ 其所属项目的对应 tab 高亮；他项目
  tab 均不高亮。
- **R7 项目色**：左栏每项目一个颜色（复用 `src/shared/project-color.ts`
  确定性色板：同 key 恒同色）；右栏 chat 以该颜色显著标识所属项目（形态见
  开放问题 ④）。
- **R8 分期**：本面（项目内会话区 + 项目色）交付且验收通过后，移除左栏顶部
  现有会话入口行（SessionTopEntry 及其出厂钮语义锚注入）。**两期不并做**——
  顶部行在过渡期保持 260904 口径（全项目混排，notes/session-tab-all-projects-decision.md
  届时标注为已退役过渡态）。

### 验收标准（第 3 面）

1. 每个项目组头下、工单列表上有一横排会话区：正方形「+」+ 正方形数字 tab。
2. 点「+」→ 在该项目主目录新建会话并切入右栏；账册登记归属该项目。
3. 点 tab → 右栏切到该会话；当前会话的 tab 高亮（且仅此一个）。
4. 点 tab 关闭钮 → 弹确认框；确认后 tab 消失（会话数据留存，可从该项目
   重新新建/恢复路径找回）；取消不关闭。
5. 每项目左栏有确定颜色（刷新/重启不变）；右栏 chat 能一眼分辨所属项目。
6. 顶部行仍按 260904 口径工作（过渡态不动）；R8 移除顶部行为**独立后续票**，
   不与本面混同验收。
7. 全部改动在工单台插件内闭环，不改 dsh 安装树；src 改动与 lib 产物同批
   （merge-checks bundle_pairs）；smoke 全绿（新增本面用例）。

## 关键决策（累计有效）

1. **只列 UI 主动打开/新建的会话**：磁盘存量、工单会话（ticket- 前缀）、
   subagent 会话一律不进账册；插件自己记账（localStorage，刷新/重启不丢）。
2. **新建走工厂同款链**：ctx.workspaces.startSession（绑工作区+复用 blank+
   正确打开），不自铸会话。
3. **样式注入走语义锚**（aria-label 等语义特征，零 CSS 类名匹配），dsh 升级
   软退化；本面新增 DOM 同样遵守。
4. **项目色确定性**：色=hash(project key)（project-color.ts 色板），不手工
   指派、不随注册表顺序漂移。
5. **关闭不删数据**：所有「关闭」语义只动入口/账册，会话本体留存平台。
6. （旧决策 2「会话跟项目走」于 260904 对顶部行废止为过渡态；第 3 面起以
   **项目内会话区**形态回归项目归属，全局顶部入口退役。）
