# localization

## What it does

One language on the interface, derived from the engine's own identifiers, while ticket text and ledgers keep their own language.

## The problem it solves

A mixed-language interface made screens hard to scan and search unreliable.

## Design and rulings

`docs/reference/writing-standard.md`; host order 260925 (English labels, data not translated).
