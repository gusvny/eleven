# console-ui

## What it does

One console with three fixed columns: what you manage on the left, what the machine is doing in the middle, the platform chat on the right.

## The problem it solves

Entry points were scattered and a progress board nobody read sat in the way; the host consolidated the entry surface and made the ticket detail an overlay in the middle column.
