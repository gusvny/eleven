# inspection

## What it does

A scheduled inspector that runs the suite, reviews the documents and hunts over-complex code, then reports findings and opens tickets.

## The problem it solves

Nothing stood between releases that would find duplicated, stale or doc-pinned tests, or code that could be simpler.
